# Dataset Reduction Experiments:

NOTE: Most probably, the config's parameters don't apply to the pilot training. The latter uses it's own defined configuration. 


1a) Generating Selection Artifact (i.e. Subset metadata) using existing pilot:

 PYTHONPATH=. python3 scripts/select_dataset.py \
  --config config/classification/cifar_resnet18.yaml \
  --pilot-checkpoint results/classification/cifar_resnet18/last.ckpt \
  --output-dir results/dataset_selection/cifar10 \
  --seed 7 \
  --el2n-low-exclusion-pct 10 \
  --el2n-high-exclusion-pct 5 \
  --kcenter-retention-pct 50

NOTE: To make el2n exclusion consider the globally best and worst confidence scores (instead of class-wise, as it does by default), use the flag: --el2n-global
(Default flag is --el2n-class-wise)

1a-cache) Precompute EL2N scores once using an existing pilot:
PYTHONPATH=. python3 scripts/compute_el2n_scores.py \
  --config config/classification/cifar_resnet18.yaml \
  --pilot-checkpoint results/classification/cifar_resnet18/last.ckpt \
  --support-size 256 \
  --batch-size 64 \
  --seed 7 \
  --output-dir results/dataset_selection/el2n_scores

1a-reuse) Create a subset using cached EL2N scores:
PYTHONPATH=. python3 scripts/select_dataset.py \
  --config config/classification/cifar_resnet18.yaml \
  --pilot-checkpoint results/classification/cifar_resnet18/last.ckpt \
  --el2n-scores results/dataset_selection/el2n_scores/last-el2n_scores.pt \
  --output-dir results/dataset_selection/cifar10 \
  --seed 7 \
  --el2n-low-exclusion-pct 10 \
  --el2n-high-exclusion-pct 5 \
  --kcenter-retention-pct 50

1b) Generating Selection Artifact using freshly trained pilot:

PYTHONPATH=. python3 scripts/select_dataset.py \
  --config config/classification/cifar_resnet18.yaml \
  --train-pilot \
  --pilot-epochs 10 \
  --output-dir results/dataset_selection/cifar10 \
  --seed 7 \
  --el2n-low-exclusion-pct 10 \
  --el2n-high-exclusion-pct 5 \
  --kcenter-retention-pct 50


2a) Global Random Selection (Random selection applied uniformly among all images):
PYTHONPATH=. python3 scripts/select_random.py \
  --config config/classification/cifar_resnet18.yaml \
  --selection-pct 68 \
  --seed 7 \
  --output-dir results/dataset_selection/global_random/cifar10


2b) Class-wise random selection (Random Selection percentage applied individually to each class):
PYTHONPATH=. python3 scripts/select_random.py \
  --config config/classification/cifar_resnet18.yaml \
  --selection-pct 50 \
  --class-wise \
  --seed 7 \
  --output-dir results/dataset_selection/random/cifar10

(NOTE: This was used to perform the comparison experiment against EL2N + K-Center Greey, because class-wise behavior is the default in the latter. Apples to Apples)



3) Train using a selected subset (All comparisons done using cifar_resnet18_kmeans_k1 model):

PYTHONPATH=. python3 main.py \
  --config config/classification/cifar_resnet18_kmeans_k1.yaml \
  --dataset-reduction \
  --selection-artifact results/dataset_selection/cifar10/selection-<id>.json \
  --seed 7

## Herding and Moderate Coreset comparison methods

All files and generated subset JSON artifacts for these methods are stored
under reduction_comparison/. See reduction_comparison/README.md.

Herding:
PYTHONPATH=. python reduction_comparison/select_reduction.py \
  --config config/classification/cifar_resnet18.yaml \
  --method herding \
  --retention-pct 51 \
  --checkpoint results/classification/cifar_resnet18/last.ckpt \
  --seed 7 \
  --gpu-limit-pct 100

Moderate Coreset (Xia et al., ICLR 2023):
PYTHONPATH=. python reduction_comparison/select_reduction.py \
  --config config/classification/cifar_resnet18.yaml \
  --method moderate \
  --retention-pct 51 \
  --checkpoint results/classification/cifar_resnet18/last.ckpt \
  --seed 7 \
  --gpu-limit-pct 100

Generated files default to:
  reduction_comparison/subsets/herding-selection-<id>.json
  reduction_comparison/subsets/moderate-selection-<id>.json

Train with either artifact using the existing commands:
PYTHONPATH=. python main.py \
  --config config/classification/cifar_resnet18.yaml \
  --dataset-reduction \
  --selection-artifact reduction_comparison/subsets/<herding-or-moderate>-selection-<id>.json \
  --seed 7 \
  --gpu-limit-pct 45
